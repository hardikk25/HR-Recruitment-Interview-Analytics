HR Recruitment & Interview Analytics Dashboard

 📌 Project Overview
This project analyzes a  HR recruitment dataset containing 5,000 applicants, The goal is to understand recruitment performance, applicant scores, interview stages, departments, locations, and final hiring outcomes.
The project follows a complete data analytics workflow:
CSV Data → Python Cleaning → Exploratory Data Analysis → SQL Analysis → Power BI Dashboard

 *Tools & Technologies
*Python— Data cleaning and analysis
 *Pandas — Data manipulation
 *Matplotlib — Data visualization
 *SQL— Database analysis
 *Power BI — Interactive dashboard
*Git & GitHub — Project version control

 📂 Dataset
The dataset contains 5,000 applicant records and 11 columns:
* Applicant ID
* Applicant Name
* Interview Date
* Experience (Years)
* Education
* Interview Round
* Technical Score
* HR Score
* Final Status
* Location
* Department

 🔎 Key Analysis
The project analyzes:
* Total number of applicants
* Offers, rejections, and applications in progress
* Offer rate
* Average technical and HR scores
* Applicants by department
* Applicants by location
* Interview round distribution
* Experience distribution
* Applicant performance
* Recruitment status by department

 📊 Key Results
* Total Applicants 5,000
* Offers: 1,000
* Rejected: 1,000
* In Progress: 3,000
* Offer Rate: 20%
* Average Technical Score: 80
* Average HR Score: 80
